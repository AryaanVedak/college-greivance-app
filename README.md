# College Grievance App  

The **College Grievance App** allows students to anonymously submit their grievances directly to the administration. Built with Flutter and Firebase Firestore, this app ensures data privacy, smooth submissions, and streamlined grievance resolution.  

## Features  

- **Anonymous Grievance Submission**  
  Students can submit grievances without revealing their identity, fostering an open and safe platform.  

- **Category Selection**  
  Users can classify grievances under categories like academics, facilities, harassment, etc., for better sorting.  

- **Real-Time Notifications**  
  Administrators receive instant notifications upon new grievance submissions.  

- **Secure and Scalable**  
  Powered by Firebase Firestore, ensuring secure storage and easy scalability.  

## Tech Stack  

- **Frontend**: Flutter  
- **Backend**: Firebase Firestore  
- **Authentication**: Anonymous Firebase Authentication
